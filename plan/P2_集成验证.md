## 环境准备

在 VPS 的 `~/.hermes/.env` 中补充：

```bash
MNEMOSYNE_EMBEDDING_MODEL=text-embedding-v4
MNEMOSYNE_EMBEDDING_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
DASHSCOPE_API_KEY=<your-key>
```

确认现有 `OPENROUTER_BASE_URL` / `OPENROUTER_API_KEY` 未被覆盖（仍供 LLM 调用）。

## 部署步骤

```bash
# 1. 本地推送到 fork
git push origin feat/chinese-fts5-bigram

# 2. VPS clone fork
cd /root/.hermes
git clone -b feat/chinese-fts5-bigram \
  https://github.com/Guang889/mnemosyne.git mnemosyne-src

# 3. 安装到 Hermes venv（editable install）
docker exec -u hermes hermes \
  /opt/hermes/.venv/bin/pip install -e /opt/data/mnemosyne-src

# 4. 重启容器
docker restart hermes
```

后续更新只需：

```bash
cd /root/.hermes/mnemosyne-src && git pull && docker restart hermes
```

## 验证步骤

### Step 1：embedding 可用性

```bash
docker exec hermes \
  /opt/hermes/.venv/bin/python -c "
from mnemosyne.core import embeddings
print('available:', embeddings.available())
v = embeddings.embed_query('测试')
print('dim:', len(v) if v is not None else 'None')
"
```

预期输出：

```
available: True
dim: 1024
```

### Step 2：写入测试记忆

在 Hermes 中依次写入：

```
/remember 腾讯云服务器配置了Tailscale和Docker
/remember 我使用Hermes-Agent作为主要AI工作流
/remember config.yaml里的custom_providers必须是list格式
```

### Step 3：FTS 直查（验证索引）

```bash
docker exec hermes sqlite3 /opt/data/mnemosyne/data/mnemosyne.db \
  "SELECT content FROM fts_episodes WHERE fts_episodes MATCH '腾 腾讯' LIMIT 3"
```

预期：返回包含 bigram token 的行（非空）。

### Step 4：召回验证

```bash
hermes mnemosyne inspect 腾讯云
hermes mnemosyne inspect Docker
hermes mnemosyne inspect list格式
```

| 查询 | 预期 |
|------|------|
| 腾讯云 | 命中第 1 条 |
| Docker | 命中第 1 条 |
| list格式 | 命中第 3 条 |

## 失败判断与回滚

触发回滚的情况：

- `available()` 返回 False 或 `dim` 不是 1024
- 写入记忆后 FTS 直查返回空
- 容器启动时 SQLite UDF 注册报错

回滚：

```bash
docker exec -u hermes hermes \
  /opt/hermes/.venv/bin/pip install mnemosyne
docker restart hermes
```
