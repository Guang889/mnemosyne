# P3：实际使用观察

**进入条件**：P2 完成
**持续时间**：1-2 周
**完成标准**：累积足够的实测数据供 P4 PR 描述使用

---

## 每周记录

| 指标 | 第1周 | 第2周 |
|------|-------|-------|
| episodic_memory 总条数 | | |
| 中文关键词 FTS 抽样命中数（3-5个词） | | |
| 然然主动引用中文历史记忆次数 | | |
| 需要重复说明背景的次数 | | |

FTS 命中抽样查询方式：

```bash
docker exec hermes sqlite3 /opt/data/mnemosyne/data/mnemosyne.db \
  "SELECT COUNT(*) FROM fts_episodes WHERE fts_episodes MATCH '腾 腾讯'"
```

---

## 进入 P4 的判断

满足以下任意一条：

- 连续使用 2 周，中文 FTS 命中率稳定 > 0（修改前全为 0）
- 出现至少 3 次然然主动从记忆引用中文背景
- 未出现任何回滚触发条件

若出现以下情况则回到 P2 排查：

- FTS 命中始终为 0
- 容器重建后 embedding 不可用（dim 异常）
